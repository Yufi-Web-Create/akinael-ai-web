# COPY_GUIDE

## Voice
- やさしいが曖昧にしない
- 説明を先に、コピーらしさは後にする
- 大げさにしない
- 売り込みすぎない
- 小規模事業者が普段使う言葉を優先する
- 専門用語は必要な場合のみ使い、短く言い換える

## Core test
文章から固有名詞を消したとき、他のAI会社・制作会社・コンサル会社がそのまま使える場合は原則として書き直す。

## Avoid by default
文脈上具体的な意味がない場合、以下の表現を避ける。
- 想いを形に
- 未来を創る
- 新しい可能性
- 寄り添います
- ビジネスを加速
- 最適なソリューション
- 革新的な
- シームレスな
- 価値を提供
- 一歩先へ

## Preferred style examples
- 契約前でも、簡易試作までは確認できます。
- まずは相談だけでも大丈夫です。
- 相談内容を整理して、必要なものから形にしていきます。
- 公開や課金などの重要な操作は、確認を取ってから進めます。

## Current brand direction
アキナエルAIは「商いの願いを叶えるAI」という名前の意味を持つが、本文のすべてを情緒的なコピーにしない。
具体的なサービス説明を優先し、ブランドコピーは必要な場所だけに使う。

## Structure
- 見出し: 何の話か理解できる
- リード: 読む理由が分かる
- 本文: 具体的な内容・条件・例外
- CTA: 押した後に何が起こるか想像できる

## Facts
- 実績、顧客名、口コミ、数字は確認済み情報のみ
- 未確認事項は断定しない
- 効果保証、順位保証、納期保証をしない
- AIだけで何でも無制限に完結する印象を与えない

## Review checklist
Copy Reviewerは最終画面の文章を読み、以下をFAIL判定する。
- generic AI copy
- 同じ意味の重複
- 過剰な敬語
- 不自然な名詞連結
- 「〜することで、〜を実現します」の多用
- 具体的な説明より抽象コピーが先行
- CTAと遷移先の意味が一致しない
- 未確認情報の断定
