# COPY_DIRECTION

最終更新: 2026-09-10（Copy Research QA反映）

## Core communication

Web担当者がいない小さなお店・地域事業者が、Web・SNS・文章・画像・調査を普段の言葉で相談し、無料試作を確認してから契約を判断できるサービス。

## Audience mindset

- 更新したいが、何から頼めばよいか整理できていない
- 制作会社へ相談するほど要件や予算が固まっていない
- 自分でツールを学び続ける時間はない
- AIの不自然さ、品質、個人情報、勝手な公開・課金が不安
- まず具体的な仕上がりと費用を見て判断したい

## Message priority

1. Web担当者がいない小さなお店・事業者向け
2. 相談内容をWeb/SNS/文章/画像/調査の作業へつなげる
3. 契約前に無料試作を確認できる
4. 公開・課金は人が確認し、カード登録なしで相談開始できる

## Voice

- 距離感: 店舗運営者と同じ机で相談内容を整理する近さ
- 文の長さ: 一文一情報、40〜70字程度を中心
- 敬語: 丁寧だが過剰にへりくだらない
- 温度: 穏やかで具体的。急かさない
- 専門用語: 原則使わず、SEO等は具体的な作業と併記
- 強さ: 保証・最上級を避け、事実と条件を先に示す

## Customer language to preserve

「料金表を直したい」「写真を入れ替えたい」「更新まで手が回らない」「まず見てから決めたい」「勝手に公開しないでほしい」。

## Words to avoid

想いを形に、未来を創る、可能性を広げる、ビジネスを加速、革新的、最適なソリューション、シームレス、AIがすべて解決、根拠のない成果表現。

## Proof before promise

- 無料範囲、料金、制作費を数値で表示
- 相談→試作→内容・費用確認→契約・制作→継続改善の順を表示
- 制作AIと品質確認、人間承認を仕組みとして説明
- 業種ページで具体的な更新対象と対応外を明示
- 架空実績・口コミは置かない

## Hero direction

- 誰向け: Web担当者がいない小さなお店・事業者
- 何をする: Web、SNS、文章、画像、調査を相談から形にする
- 最初の行動: 無料でAIに相談する
- Tone: ブランドコピーは一行だけ。直後に具体説明
- Avoid: 「AIで事業を変革」のような抽象的な技術訴求

## Section copy direction

- Problem / solution: 「更新が止まる」「料金表を直す」等の行動語で書く
- Process: 各段階で顧客に何が見え、何を判断するかを示す
- Pricing: 税込、無料範囲、追加作業の事前承認を明記
- FAQ: 料金、公開、無料範囲、品質、データ、解約の不安を先回り
- CTA: 押した後に無料登録→Portal→相談となることを説明
- Industry: 予約、営業日、体験申込み、対応エリア等の固有語を必ず含む

## Generic-copy test

「アキナエルAI」を他社名へ置換して成立する見出しは、対象・作業・順序・承認条件のいずれかを追加する。ブランドコピー「商いの願いを叶えるAI」は単独で使わず、直後に対象と対応範囲を置く。

## Reference relationship

競合の「無料」「簡単」「業種別」という機能原則は参照するが、コピーは転用しない。アキナエルAI固有の相談起点、無料試作、人間承認、制作と検査の分離を中心に構成する。
