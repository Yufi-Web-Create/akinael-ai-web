# design-input

Temporary local handoff area for design source assets used during the PHASE 8.5 Visual Quality Rebuild.

Place the Work-generated asset pack here, for example:

```text
design-input/
  akinael-visual-assets-v1/
    images/
    README.md
    contact-sheet.jpg
```

Claude Code should review assets from this folder first, then copy only approved/optimized production assets into `public/assets/`.

Files placed here are design inputs only and must not be referenced directly by production pages.
