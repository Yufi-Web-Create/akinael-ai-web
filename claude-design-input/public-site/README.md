# Handoff: アキナエルAI ランディングページ

## Overview
小規模店舗・地域事業者向けのAI活用制作・運用支援サービス「アキナエルAI」の1枚LP。サービス概要、課題訴求、提供価値、提供内容、利用フロー、料金、CTAで構成する。

## 実装前提
Claude Design由来のHTMLは見た目と挙動の参照用であり、productionコードとしてそのままコピーしない。現在の `akinael-ai-web` のAstro構成と既存パターンを維持し、Astroコンポーネントとして再構築する。

## Fidelity
High-fidelity。最終的な配色・タイポグラフィ・余白・インタラクションを反映したモックアップとして扱い、主要画面は高い再現度で実装する。

## 画面構成
### 1. ナビゲーション
- 左: sparkleアイコン + 「アキナエルAI」
- 右: 「選ばれる理由」「できること」「料金」「ログイン」「AIに相談してみる」
- 狭い画面はflex-wrap。ハンバーガー前提ではない。

### 2. ヒーロー
- 見出し: 「商いの願いを、」「AIが叶えます。」
- CMYKの版ズレ表現。cyan / magenta / yellowをわずかにオフセット。
- CTA: 「AIに相談してみる」/「料金を見る」
- チップ6個:
  - まずは無料でおためし
  - 普段の言葉でOK
  - 専門知識は不要
  - 成果物を見てから契約
  - 最終確認は人がします
  - 小さな商いにやさしい価格

### 3. 課題訴求
3カラム:
- 更新する人がいない
- 頼れる先が見つからない
- AIを使いこなせない

### 4. 提供価値
新聞の題字のような太罫線＋細罫線で囲む。6項目を番号01〜06付き2カラムグリッドで表示。

### 5. できること
カード6枚:
- AI相談・集客相談
- SNS投稿案・キャッチコピー
- Webサイト・LP制作・改善
- チラシ・バナー制作
- 簡易リサーチ・施策提案
- 継続的な制作・運用支援

### 6. ご利用の流れ
左に7ステップ:
1. AIに相談
2. 内容整理
3. AIによる提案・制作
4. プレビュー確認
5. 修正
6. 人による承認
7. 公開・利用

注記: 「公開や課金の前には、必ず人の目で確認します。」

右に実プロダクト画面6枚のスクリーンショットスライダー。3.5秒ごとに自動切替、opacity 1.1秒 easeのクロスフェード、ドットクリックで任意画像へ移動。

### 7. 料金
セグメントコントロールで「継続サポートプラン」/「単体メニュー」を切替。

継続サポート:
- お試し ¥0
- 本契約ミニ ¥3,980/月
- しっかり運用 ¥7,980/月
- 発展運用 ¥17,800/月

単体メニュー:
- Web正式制作・公開 ¥19,800〜
- Instagram広告運用 広告費の20%（最低¥5,500/月）

注意書き:
- 外部費用は顧客負担
- プラン外作業は承認後開始
- 承認前に無断課金・公開しない

正式な料金Source of Truthと矛盾する場合は既存仕様を優先して確認し、課金ロジックを勝手に変更しない。

### 8. 最終CTA
「まずは無料で、相談してみませんか？」＋「AIに相談してみる」。

### 9. フッター
サービス名＋短い説明。

## Interactions
- 料金切替はローカルstateのみ。
- hover / active / focus-visibleを実装。
- ヒーローCMYKのポインター追従は低優先。静的版ズレだけでも可。
- レスポンシブはCSS Grid auto-fit/minmaxとflex-wrapを基本とする。
